老显卡跑 llama.cpp 说明
================================================

写给手上是 GTX 10 系（或更老）的朋友看的。
一句话结论：能跑，但别装最新的 CUDA。

────────────────────────────────────
先说结论
────────────────────────────────────

GTX 1060 / 1070 / 1080 / 1080 Ti 这些 Pascal 架构的卡，

   能跑，但要选 cuda-12 的包，不能选 cuda-13。

GTX 970 / 980 这些 Maxwell 的，
   同样只能用 cuda-12。

────────────────────────────────────
为什么
────────────────────────────────────

NVIDIA 在 CUDA 13.0 里把 Maxwell / Pascal / Volta 的支持删掉了。
官方原话：

   "Offline compilation and library support for these architectures
    have been removed in CUDA Toolkit 13.0 major version release."

坑在于：nvidia-smi 里显示的 "CUDA Version" 是【驱动】能支持的最高版本，
不是你这张卡【架构】能用的版本。

所以一块装着最新驱动的 1060，nvidia-smi 照样会显示 CUDA 13.5。
看到这个数字就下 cuda-13 的包 → 几百 MB 下完，启动直接报：

   no kernel image is available for execution

这不是你装错了，是这张卡根本跑不了 CUDA 13 编译出来的东西。

────────────────────────────────────
怎么判断自己该用哪个
────────────────────────────────────

看 compute capability（计算能力），分界线是 7.5：

   显卡                        CC      该用
   ────────────────────────────────────────────
   GTX 970 / 980  (Maxwell)    5.2     cuda-12
   GTX 1060/1070/1080 (Pascal) 6.1     cuda-12
   Tesla V100     (Volta)      7.0     cuda-12
   RTX 2060 及更新 (Turing+)   7.5+    cuda-13

查自己的 CC：

   nvidia-smi --query-gpu=compute_cap --format=csv

输出 6.1 就是 Pascal，7.5 以上才轮到 CUDA 13。

老驱动没有这个查询项的话，看显卡型号就知道：
型号里带 GTX 10 或 GTX 9 的，一律用 cuda-12。

────────────────────────────────────
还有个更省事的选择：Vulkan
────────────────────────────────────

llama.cpp 的 Windows 包除了 CUDA 版，还有 Vulkan 版。

   · 只有 37MB（CUDA 版主程序 + 运行库要 600MB 以上）
   · 不用装 CUDA 运行库
   · 跨厂商，AMD 和 Intel 的卡也能用
   · 对老架构的支持反而更好

老卡如果 CUDA 版各种报错，直接换 Vulkan 版试试，多半能跑起来。
速度会比 CUDA 慢一些，但能跑起来比跑不起来强。

────────────────────────────────────
性能预期（别抱太高希望）
────────────────────────────────────

GTX 1060 6GB：
   能跑 7B～8B 的 Q4 量化模型
   上下文 16K 左右比较稳
   速度大概每秒几个 token —— 能用，但明显慢

GTX 1060 3GB：
   只能跑 3B 以下的模型，或者把上下文压得很小
   体验会比较勉强

原因：Pascal 没有 Tensor Core（那是从 Turing 才开始的），
矩阵运算全靠普通 CUDA 核心硬算。

────────────────────────────────────
如果嫌手动折腾麻烦
────────────────────────────────────

我这边有个启动器，会自己判断显卡该用哪个包：

   https://github.com/lukankan123/local-llm-launcher

它会读 compute capability，老卡自动选 cuda-12，新卡选 cuda-13，
不会让你下错包。也支持自动扫描模型目录、自动配参数。

纯脚本，PowerShell 写的，不放后台、不联网传数据。

────────────────────────────────────
最后
────────────────────────────────────

老卡不是不能用，是工具链把它甩下了。
只要别盲目装最新，它能干的活还不少。

有问题随时问。
